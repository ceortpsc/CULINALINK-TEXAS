# Tests

## Test 1 - Verify live discovery contains only current verified production records [sanity]
Viewport: desktop
Covers: GET /api/marketplace/live, verified-only public discovery, no synthetic production data
Description: Verifies the live marketplace never auto-creates demo professionals and only exposes current verified provider records.
Steps:
1. Open Discover and refresh the marketplace
2. Inspect every returned professional card, if any
3. Open the verification detail for one visible professional when a record exists
Expected: Every visible professional has current CulinaLinkTX verification; no demo, sandbox, example professional, fabricated rating, or synthetic opportunity appears. An empty marketplace is valid when no verified production records exist.
