# Privacy and Data Request Runbook

1. Authenticate the requester.
2. Record request type: ACCESS, CORRECTION, DELETION, PORTABILITY, OPT_OUT or APPEAL.
3. Identify relevant systems and processors.
4. Apply retention/legal-hold checks.
5. Fulfill eligible request actions using least privilege.
6. Record completion evidence and exceptions.
7. Notify processors when contractually/legally required.
8. Provide a response and appeal path where applicable.

Deletion is not a blind cascade: financial, tax, fraud-prevention, dispute, security and audit obligations may require retention of specific records. Eligible personal data should be deleted or deidentified after review.
