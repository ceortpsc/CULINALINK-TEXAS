# Verified-Only Production Seeding

Production seed scripts may contain only authoritative CulinaLinkTX reference configuration such as service categories, status taxonomies, workflow definitions and jurisdiction/configuration records owned and reviewed by the platform.

Production seed scripts must not insert synthetic customers, providers, businesses, orders, bookings, reviews, ratings, payments, payouts, compliance outcomes or verification results.

Real operational records enter production only through authenticated user actions, authorized administration, verified migrations or authoritative integration events.
